Workflow recommandé
Étape 1 — Génère le fond

Commence uniquement par l’image principale.

Objectif :

obtenir l’ambiance parfaite,

les couleurs correctes,

la foule réaliste,

la lumière nigérienne authentique.

Étape 2 — Génère les PNG des lutteurs

Une fois le fond validé, génère les deux lutteurs séparément.

Ils doivent :

avoir le même angle de lumière,

la même direction de regard,

une pose compatible avec le fond.

Étape 3 — Intégration dans le Hero

Tu les placeras en :

absolute positioning

mix-blend-mode léger

drop-shadow

parallax avec Framer Motion

Exemple d’effet premium
Animation d’entrée

Lutteur gauche : slide from left

Lutteur droite : slide from right

Arbitre : fade + scale

Poussière : opacity pulse

Animation au scroll

Les lutteurs se rapprochent légèrement.

Le fond se déplace plus lentement.

La poussière flotte subtilement.

Résultat :

effet cinématique,

identité forte,

sans vidéo lourde,

60 FPS sur mobile.

Petit conseil ultra important

Quand tu génères les PNG détourés, ajoute toujours :

“transparent background”

Sinon l’IA te donnera un faux fond noir ou gris.
